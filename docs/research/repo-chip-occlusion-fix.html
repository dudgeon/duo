1 · Five mitigation options

Option A · Truncate chip with ellipsis
Hard cap the chip width (~120px). Long branch names truncate with "…"; hover the chip → full tooltip. Folder name always wins on visibility. No animation.

2 · Pick an option

Q1 · Chip mitigation strategy
Which option ships?

Trade-offs at a glance:

  • A simple, full chip when it fits / truncates when it doesn't, tooltip for full.
  • B cleanest visual, but loses at-a-glance scanning.
  • C most info, doubles row height for repo rows.
  • D at-a-glance preserved, hover transition can feel busy.
  • E always-visible state (the most useful bit) + branch truncates — closest to "do what most users need."
Q2 · Chip max width (optional tuning)
How much horizontal space should the chip get?

Most relevant for A and E. Width tradeoff: bigger = more branch text visible, smaller = more name visible.
