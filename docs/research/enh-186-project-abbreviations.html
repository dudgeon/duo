Project rail — tile abbreviations

ENH-186. The project rail labels each tile with a short abbreviation of the folder name. The old rule took the first two characters, so every ai-* / aipm-* project collapsed to a duplicate “AI” tile. This change derives word-aware initials and resolves collisions across the whole visible set.

The rules
  • Multi-word name → first letters of the first two words (ai-pm-tools → AP).
  • If two tiles collide because their first two words match → expand to three initials (APT / APD).
  • Single-word name → first two letters (platform → PL); on collision, grow one letter at a time (PLAT / PLAN).
  • Proposed fallback for collisions the letter ladder can’t break (e.g. ai-pm-data vs ai-pm-dashboard — both APD): a numeric suffix by sort order (APD, APD2). The first tile keeps the clean form.
