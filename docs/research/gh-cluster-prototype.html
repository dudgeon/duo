1 · The two-state spatial logic

Today's Navigator can be in one of three positions for any open repo:

  1. Repo root IS the topmost row in the tree → show inline chip next to it.
  2. Repo root is somewhere in the visible tree, but with siblings → still show inline chip (this is the same as case 1 — multiple repos visible).
  3. Repo root is NOT in the visible tree (user navigated into the repo so the breadcrumb is `~/repos/duo/src/` rather than `~/repos/`) → no chip is reachable; show a ribbon banner above the tree that acts as a proxy for the repo root.

6 · Summary of locked v1 decisions (carrying forward, not re-asking)

  • Chip text format: clean=main, dirty=main · 3 modified, diverged=main · 2 ahead, 1 behind.
  • No icon next to chip text (text-only).
  • Inline chip placement when root visible — Q1 above covers when root NOT visible.
  • GH Enterprise hosts: detected via remote URL prefix.
  • Auth-failure: menu items show regardless (public-repo URLs don't need auth).
  • Dirty dot: any-change semantics (staged/unstaged/untracked → one dot).
  • Refresh trigger: fsevents-driven, debounced 250ms.
