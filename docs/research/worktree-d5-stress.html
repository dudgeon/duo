What we already know (measured on this machine, 2026-06-14)

Agents demonstrably DO create worktrees. There are 14 claude/* worktrees live under .claude/worktrees/ right now — every one created by Claude Code's own harness, not by hand. The detect-only premise (agents make their own worktrees) is not hypothetical; it's the steady state.
An agent can already self-identify. duo worktree run from inside a worktree returns isCurrent: true + the branch — so an agent can answer "am I in a worktree, and which?" with one shipped verb today. The fields isLinkedWorktree / mainWorktreeRoot / repoName also ride on getGitStatus.
The verb is discoverable. duo worktree is documented in agents/duo.md + docs/CLI-COVERAGE.md + the skill's cli-reference.md (the Haiku-subagent cheat-sheet). Gap: it's not yet in skill/SKILL.md proper (soft nit; the currency check passes via cli-reference.md).

The gate this test informs

B — detect-only shipped

Duo reads + displays worktrees (tab chip, working-pane badge, navigator section, duo worktree). Agents create/clean via plain git worktree / Claude Code's own mechanism. Holds if agents create + clean reliably on their own.

C — Duo-managed lifecycle not built

Add duo worktree new <branch> / duo worktree remove + a "new Claude session in worktree…" gesture + stale-worktree prune UX. Build only if the test shows agents stumble (don't create, collide, or leave a mess) often enough to matter.

Harness sketch (how a live run would work)
  • Spawn a shell terminal via the new-terminal gesture in a throwaway clone; start claude; wait for claudePresence to detect it.
  • duo send a task that implies a worktree ("work on X on a new branch without disturbing main"); observe whether it runs git worktree add / reaches for duo worktree.
  • For S2, repeat in a second window (duo window new); confirm distinct hues + per-window isCurrent.
  • Use a unique test-run worktree prefix + a finally cleanup so the test never collides with the 14 real worktrees.
  • Validate the single-agent path (S1/S3) before attempting parallel (S2) so a flaky harness isn't mistaken for an agent failure.
