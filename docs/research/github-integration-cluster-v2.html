3 · Right-click "Open on GitHub" / "Copy GitHub URL" (ENH-155)

New Navigator right-click items, only shown when the path is inside a git repo with a GitHub remote:

Open in editor
Open in canvas
Clone GitHub repo here…
Open on GitHub
Copy GitHub URL
New folder…
Move to Trash…

URL shape. Files → https://github.com/<owner>/<repo>/blob/<branch>/<rel-path>. Folders → /tree/ instead of /blob/. Resolves git remote get-url origin + git rev-parse --abbrev-ref HEAD via the existing core/git/ helpers ENH-152a uses.

Q4 · GitHub Enterprise support
Should "Open on GitHub" work for github.<company>.com enterprise hosts?

Detect via gh auth host (gh auth status returns the host of the authenticated config) vs. URL prefix match.

Q5 · Auth-failure case
If gh auth status reports no auth, should the right-click menu items still appear?

Public repo links don't require auth. Only writes need auth.
