OKF rollup — planned template

ENH-229 · the skill emits one of two variants per rollup — HTML or Markdown, chosen at generation. Not one artifact with a toggle.

Two mutually-exclusive variants. duo rollup render <note> --html writes an HTML artifact; --md writes a Markdown file. Pick one. Both carry entity links on every row (task→note, owner→person, group→initiative) and — for the standard rollup — a change summary written by interactive Claude on regenerate (narrative + notables, optional/disableable).

Variant B — Markdown file

GitHub-portable: links + table render natively. The summary lives in frontmatter + a "What changed" blockquote; the rows snapshot rides in a trailing HTML comment so the next regenerate can diff. Refresh-from-MD is the fast-follow (duo://rollup/refresh link intercept); for now you regenerate from the terminal.



How the change summary works (req #7)




Interactive Claude, not headless; the user just accepts; optional. On refresh, the rollup re-evaluates, the CLI computes the deterministic diff against the artifact's embedded snapshot, and an interactive Claude turns that diff into a narrative + notables. --no-summary disables it.


Refresh -> duo:event(rollup:refresh) -> `duo rollup watch` (interactive Claude)
        -> duo rollup diff (deterministic) -> Claude writes narrative+notables
        -> duo rollup summary --text "..." -> regenerate -> reload
MD fast-follow: [refresh](duo://rollup/refresh?base=tasks) -> will-navigate -> same event


Placement = both: latest summary pinned at the top of the artifact; prior regenerations collapse into the change history.
