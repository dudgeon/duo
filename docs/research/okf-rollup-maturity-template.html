How the two new bits work




Entity links (req #6). The serializer resolves each row to its source note and renders a link; linked frontmatter values (owner, initiative) resolve to their entity notes; group headers link to the group entity. Only resolved corpus entities link — unresolved values stay plain text (never a fabricated target).


OKF (portable):  [Legal review](./notes/legal-review.md)   [Alice Park](./people/alice-park.md)
HTML render:     <a href="./notes/legal-review.md">Legal review</a>   (Duo opens it on click)



Refresh (req #5). The button is declarative — data-duo-action="duo:event" emitting rollup:refresh. A tiny duo rollup watch subscribes to the existing event bus, re-renders, and reloads. A button can't re-render itself — it requests; the watcher fulfills.


HTML now:        Refresh → duo:event(rollup:refresh) → `duo rollup watch` → re-render → reload
MD fast-follow:  [↻](duo://rollup/refresh?base=tasks) → will-navigate intercept → same event
