Invocation surfaces

Five paths now converge on a single state-mutation primitive (splitViewMoveTabByPath in App.tsx). Pick whichever feels natural in the moment.

  • ⌘\ chord — moves the active main file tab into aux.
  • ⌘⇧\ chord — closes the split.
  • Right-click a tab in the WorkingTabStrip → Move to Split View (file tabs only; browser tabs gated until 3c-iv).
  • Right-click any file in the navigator (FileTree) → Open in Split View.
  • Right-click any file pin in PinnedNav → Open in Split View.
  • (Already shipped pre-session) Per-page <meta name="duo-path-target" content="split"> + per-link data-duo-target="split" for browser-pane page links.

Phase 3c-i
Shipped

Session persistence

Aux state survives a Duo relaunch. Quit Duo with a Split View open, relaunch, and the same files are in the same panes at the same divider position. Implemented as an additive field on SessionState (no schema-version bump; old saves stay valid). Renderer save serializes auxState; restore runs the same fs.exists existence-check pattern as fileTabs (BUG-039 lineage) — drops paths that no longer exist on disk; rehydrates with clamped activeIndex + splitPct.

Touched: shared/types.ts (new SessionStateAux interface + optional aux field), core/session-state-service.ts (defensive validateAux helper), App.tsx (save + restore wiring). Commit e5c8eb7.

Phase 3c-iii
Shipped

Dirty-replace dialog

When the aux pane is showing a file with unsaved changes and you (or the agent) try to open a different file in aux, Duo fires a native macOS dialog.confirm: Cancel (default — preserves the current aux) or Discard changes (replaces, losing the unsaved edits). Clean aux files replace silently with no dialog. Same gate fires across all five entry points — chord, three right-click menus, CLI / page-link IPC.

Foundation: a path-keyed dirtyPaths: Set<string> in App.tsx that bridges main fileTabs (random uuids) and aux tabs (synthesized aux:${path} ids). The existing onTabDirtyChange resolves both id flavors back to canonical paths and mirrors into the Set. v1 dialog has no Save button — saves are per-editor + async; the "save manually first" flow is the intended escape valve until a save-by-path dispatch exists.

Originally deferred to v0.6.5 in the AUQ session — pulled forward here because the foundation was small enough to fit. Commit e54eb3b.

Vitest framework + first 100+ regression tests brand new this session

Closes the "recurring regressions need durable test coverage" memory feedback. The BUG-061 markdown-trigger class cycled through three implementations (v1 strict-eq → v2 start-match → v3 nbsp-tolerant) — without tests, a v4 iteration would have to re-discover the Chromium nbsp quirk at smoke-walk time.
