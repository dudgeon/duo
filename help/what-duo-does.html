What Duo does

A plain-English reference of every substantial thing Duo can do, with a use case and the way to invoke it. Many items have both a UI path and a duo CLI command — the CLI is what you ask Claude to use when you want the agent to drive Duo for you. Numbered for quick reference: "see item 23."

Editing files

Markdown documents, HTML canvases, and the shared toolbar conventions.

1

Edit markdown files

Open any .md file as a rich editor in the working pane — formatting toolbar, markdown shortcuts on typing, autosave.

UIClick the file in the navigator. CLIduo edit <path.md>

2

Markdown shortcuts on typing

Type # to make a heading, - / * / + for a bullet (the marker character is preserved visually — - renders as an en-dash, + as a plus, * as the default disc), **bold** for bold, 1. for a numbered list, > for a quote, --- for a divider, ``` for a code block. Press Enter twice on an empty line inside a bullet, ordered list, or blockquote to exit it. Works in both the markdown editor and the HTML canvas. v0.6.5+ for the marker-passthrough + blockquote double-Enter exit.

UIJust type. The shortcut fires on the space or Enter that ends the trigger.

3

Use the formatting toolbar

Heading picker, B/I/U/S, link picker, bullet / ordered / task lists, blockquote, code block, horizontal rule, table insert, undo/redo, save. Same toolbar in the markdown editor and the HTML canvas.

UIClick a button at the top of the editor.

4

Edit tables in place

Insert a table with the table button. When the cursor is in a cell, a contextual second toolbar row appears: add row above/below, add column left/right, delete row, delete column, toggle header row, delete table.

UIClick into a cell.

4b

Copy a code block

Hover any <pre> in the markdown editor or HTML canvas — a Copy button appears top-right. Click it; the code text lands on your clipboard.

UIHover the code block. v0.5.1+

4c

Find text in the markdown editor

⌘F opens a find bar above the prose. Type a query; matches highlight inline with a counter (3/47). ↓ / ↑ (or ▼ / ▲ buttons) navigate to the next/prev match with a smooth scroll. ⎋ closes. Case-sensitive toggle (Aa) is a click. Works in dark mode without the previous contrast issue.

UI⌘F. v0.5.3+

4d

Indent / outdent list items

Inside a bullet, ordered, or task list, ⌘] indents the current item (sinks it into a sub-list); ⌘[ outdents (lifts it back). Outside a list the chord no-ops. Familiar from Obsidian / Bear / Notion. Works in both the markdown editor and the HTML canvas (canvas parity shipped v0.6.5; markdown editor since v0.5.3). Tab / Shift-Tab also indent / outdent inside list items in both surfaces.

UI⌘] / ⌘[ (or Tab / Shift-Tab) inside any list item.

4e

Tell the agent to scroll the editor

When Claude is working with you on a long doc, this gets it to land you both at the same spot without you having to scroll-and-search. --heading matches by heading text; --line by 1-indexed source line; --anchor by GitHub-slug (so --anchor "bug-038" matches the heading ### BUG-038: …). Response includes matched_heading so the agent can confirm it landed on the right entry.

CLIduo doc goto [<path>] --heading "X" | --line N | --anchor "Y" · v0.5.3+

4f

Have the agent search the editor's live buffer

Read-only counterpart to duo doc goto. The agent gets back the matching lines + counts without scrolling you anywhere. Use when the agent needs to know "is this term in the doc, and where?" without disrupting your view.

CLIduo doc find "<query>" [<path>] [--case-sensitive] · v0.5.3+

4g

Right-click for the usual context menu

Right-click anywhere in the markdown editor, HTML canvas, or browser pane to get Cut / Copy / Paste / Select All / Look Up "selection" / Spell-check suggestions. In dev builds you also get Inspect Element. Browser tabs get the link / image variants too (Copy Link, Save Image As, etc.) when you right-click a link or image.

UIRight-click. v0.5.4+

4h

Copy without formatting

When you copy from a rich source, Duo's "Copy as Plain Text" gives you just the text — no markdown marks, no HTML tags, no bold/italic. Pastes cleanly into terminals, plain-text fields, anywhere you don't want formatting following along.

UIRight-click selected text → "Copy as Plain Text", or ⌘⌥C from the keyboard. v0.5.4+

5

Edit an HTML file as a live canvas

Open any .html file as a rendered, editable canvas — what you see is what gets saved. Same toolbar as the markdown editor, plus markdown shortcuts on typing.

UIClick the file in the navigator. CLIduo edit <path.html>

6

Create a new file

Make a new markdown file or HTML canvas from a filename interstitial — type the name, hit Enter, start typing.

UIClick + on the working-pane tab strip. Type a filename ending in .md or .html. CLIduo html new <path.html>

7

Add comments to a document — markdown editor or HTML canvas

Both surfaces have the same comment UX. Select text, then any of: press ⌘⌥M (Google Docs parity), right-click and pick "Comment", or click the 💬 button on the toolbar. Comments persist in a sidecar (<file>.md.duo.json or .html.duo.json) — the source file stays clean. The commented text shows a soft orange highlight. Click rail thread → anchor strengthens; click anchored text → rail thread focuses (bidirectional). Resolve a thread and the body highlight disappears. Closing + reopening the file rebuilds the rail with comments + decorations re-applied.

UISelect text → ⌘⌥M / right-click "Comment" / toolbar 💬 → write → ⌘+Enter. CLIduo html comment --id <duo-id> --body "…" (canvas only)

8

See what the agent just changed

When Claude pushes an edit (markdown editor or HTML canvas), the changed region paints yellow and fades to transparent over ~6 seconds. Reopening a file within the freshness window repaints recent edits — useful for catching up on background agent work.

UIWatch the canvas after running an agent edit.

9

Get warned before an agent overwrites your unsaved edits

If you have unsaved changes and the agent tries to write the same file, a banner appears with a preview of the agent's intended write and Apply / Decline buttons. Decline returns an error to the agent saying you declined.

UIRead the banner, choose Apply or Decline.

Browsing the web

An embedded Chromium pane. Tabs, address bar, the same shortcuts you'd expect.

Open a browser tab

A real Chromium tab inside Duo. Logged-in sessions persist between launches.

UIClick > on the working pane's split-button (right of the tab strip), or ⌘T while the browser pane has focus. CLIduo open <url>

10b

Reopen the last-closed browser tab

Closed something by accident? Same gesture you use in Chrome.

UI⌘⇧T while the browser pane has focus. (From any other focus, ⌘⇧T spawns a new Claude tab.) v0.5.1+

11

Jump to the address bar

Type a URL or search term without reaching for the mouse. Start typing → suggestions from your visited-history match as you type (sorted by recency × visits).

UI⌘L from anywhere in the working pane. Arrow keys to pick a suggestion; Enter commits.

12

Navigate the browser

Back, forward, reload — useful when you're asking Claude to drive a multi-step web task.

UIBrowser pane controls. CLIduo back · duo forward · duo reload

13

Open a link in your real browser

Off-host or work-restricted URLs (SSO, internal sites, bookmarks-only) belong in your default browser, not Duo's embedded Chromium. Duo will route them out automatically when the domain is on the external list.

CLIduo external <url> — or just paste a URL into a Duo terminal and let Claude decide.

13b

Find text on the current page

⌘F opens a find bar above the address row when the browser pane is active. Matches highlight on the page; the bar shows "n/m" so you know where you are. Enter or ⌘G goes to the next match; ⇧Enter or ⌘⇧F goes back. ⎋ closes and clears highlights.

UI⌘F (browser pane focused). v0.5.4+

16

Have Claude show you a file in the navigator

When the agent finds a relevant file, it can scroll the navigator to that path and select the file — useful when you've asked for "the config that controls X."

17

Collapse the file column to a rail

More room for the terminal and the working pane when you don't need to navigate. The collapsed rail shows a folder glyph plus a vertical "Navigator: {project_name}" label so you know which project's tree is hiding behind it (useful when you have multiple Duo windows open). 17a

See and clear navigator selection easily

Selected file or folder rows in the navigator paint with a stronger accent fill plus heavier weight (Finder-style — at-a-glance visible). Three ways to clear selection: click the same row again, click any whitespace below the row list, or press Escape. v0.6.5+

UISingle-click to select; click again / click whitespace / Escape to deselect.

17b

Open a file from Finder into Duo

Duo registers as a macOS Open With candidate for .md and .html files. Right-click any markdown or HTML file in Finder → Open With → Duo, and the file lands in the working pane via the same smart-routing path as duo open (markdown → editor; HTML → canvas, or browser if its duo-open-in meta says so). Set Duo as the default for an extension via Get Info → Open With → Change All. Cold-start is supported — opening a file from Finder while Duo is closed launches the app and routes the file once the renderer mounts. v0.6.5+ (signed DMG only)

UIRight-click a file in Finder → Open With → Duo, or set Duo as default for the extension.

Terminal & Claude

Multiple terminal tabs. Each one knows it's running inside Duo.

18

Open a vanilla shell tab

A regular zsh / bash session, useful for scripts you don't want Claude in.

UIClick > on the terminal tab strip, or ⌘T while a terminal has focus (opens at the front terminal's CWD). CLIduo new-tab --shell v0.5.3+

18b

Paste into the terminal without auto-executing

When you copy a command from chat or a doc, the source usually appends a trailing newline. Pre-v0.6.7, pasting that into a Duo terminal auto-executed the command before you could read it. Now Duo strips trailing newlines from the clipboard payload (matches Terminal.app's default). Internal newlines stay intact — multi-line paste for Claude Code prompts, heredocs, REPL blocks, and shell scripts still works. v0.6.7+

UIJust paste (⌘V). The trailing newline is dropped automatically; no opt-in required.

19

Open a Claude tab

A new terminal tab that auto-launches Claude Code (when claude is on your PATH). Title shows claude · <basename> until the REPL detects.

UIClick + on the terminal tab strip, or ⌘⇧T from anywhere — from terminal focus, opens at the front terminal's CWD. CLIduo new-tab --claude

20

Cycle terminal tabs from the keyboard

Move between active conversations without reaching for the mouse.

UI⌃Tab forward, ⌃⇧Tab back. Pane-aware: cycles browser tabs when the browser is focused.

21

Let Claude detect it's running inside Duo

Every terminal Duo spawns gets DUO_SESSION, DUO_SOCKET, DUO_VERSION, and TERM_PROGRAM=Duo in its environment. Claude (or any tool) can branch on these to enable Duo-specific behavior.

CLIecho $DUO_SESSION from any Duo terminal.

Capture & send

Get a quote, an excerpt, or a selection from any pane into the conversation with Claude.

22

Send a selection to your active terminal

Highlight text in the markdown editor, the browser pane, or the HTML canvas — a "Send → Duo" pill appears. Click it; the selection lands in your active terminal as quoted text with a path / URL trail so Claude knows where it came from. v0.5.1+: the pill only shows when your front terminal has Claude actually running; if you're at a shell prompt the pill stays hidden so you don't accidentally pipe text into a non-Claude session.

UISelect text → click the pill (when visible).

23

Choose how the agent receives your selection

Three formats: provenance + quote (default), literal text only, or an opaque token Claude can dereference. Agents preferring small payloads use the token form and look up the full text via duo selection.

CLIduo selection-format a|b|c

24

Have Claude read your current selection

Whatever's selected in any pane — markdown editor, browser, canvas — comes back as JSON: text, surrounding context, anchor (for canvas), URL or path. Used by the agent to answer "summarize what I'm looking at."

CLIduo selection [--pane auto|editor|browser|canvas]

Agent ops on the canvas

The CLI that lets Claude read and write your live HTML files structurally.

25

Query the canvas DOM

Ask Claude to find elements by CSS selector or by their stable data-duo-id — returns count, sample text, and structural info. Useful for "how many h2s are in this document?"

CLIduo html query --selector "h2" · duo html get --id <duo-id>

26

Have Claude rewrite a section

Replace the inner HTML of a specific element by stable ID. Yellow wash highlights the change; the warn-before-overwrite banner appears if you have unsaved edits.

CLIduo html set --id <duo-id> --html "<p>new content</p>"

27

Have Claude append content

Add new HTML inside an existing element without replacing what's there.

CLIduo html append --id <duo-id> --html "<li>new bullet</li>"

28

Have Claude remove an element

Delete an element by ID. No yellow wash because there's nothing to highlight.

CLIduo html remove --id <duo-id>

29

Have Claude change an attribute

Set or unset attributes on an element — a class, a data-*, an href.

CLIduo html attr --id <duo-id> --name class --value "highlight"

30

Have Claude leave or list comments

Claude can leave a comment anchored to any element (resolved by ID, by selector, or by surrounding text). Or list every thread on the page, filtered by status.

CLIduo html comment --id <duo-id> --body "…" · duo html comments [--filter open|resolved|all]

30b

Have Claude click a canvas button

Synthesizes a click on any canvas element by ID or CSS selector. The element fires its own click handler — which may emit a data-duo-action event, may invoke an in-page handler, or may do nothing. Used by the lesson fly-through harness to walk every step of a lesson without manual interaction. Read-only op (doesn't generate a recentEdits entry). Pairs with duo events --follow --since: agent subscribes to the lesson's event stream, clicks the next-step button as each step:N-done event fires, advances through the lesson autonomously.

CLIduo html click --id <duo-id> · duo html click --selector "button.advance"

30c

Live events from browser-pane pages

Agent-emitted HTML pages opened in Duo's browser pane (smoke walks, sprint plans, retros, custom dashboards) can fire data-duo-action events that Claude sees live via duo events --follow — same vocabulary that's worked in canvas iframes since Stage 23. Click a PASS / FAIL / SKIP radio in a smoke walk, Claude sees the answer in real time; no copy/paste round-trip. Inline JS in the page can also call window.duoPlaygroundAction(jsonBundle) directly to fire structured actions on change / input / blur events that don't fit the click-driven contract. The runtime is injected on every file:// page Duo opens; arbitrary http(s) sites stay inert. v0.6.6+

HTML<button data-duo-action="duo:event" data-event="walk:done"> · JS escape hatchwindow.duoPlaygroundAction(JSON.stringify({attrs: {...}})) · Subscribeduo events --follow

Look & feel

Atelier visual identity — paper-cream surfaces, warm ochre accents, light by default.

51

Snap pane sizes (terminal vs canvas)

Drag the divider between the terminal column and the working pane to resize, or pick a preset. Range is 20–80% terminal column. Useful when you want to focus reading (canvas-heavy) vs typing (terminal-heavy) without fiddling.

UIDrag the divider, or View → Pane size → Even / Terminal heavy / Canvas heavy / Full terminal / Full canvas. Keyboard⌘⌥1 (terminal heavy 67/33), ⌘⌥2 (even 50/50), ⌘⌥3 (canvas heavy 33/67), ⌘⌥0 (full terminal), ⌘⌥9 (full canvas). CLIduo split <pct> (numeric, 0–100, clamped to 20–80) or duo split <preset> (even, terminal-heavy, canvas-heavy, terminal, canvas).

52

Collapse a pane all the way (terminal or canvas)

Two buttons in the titlebar (next to the theme toggle) hide the terminal column or the canvas (right pane) all the way. The collapsed slot becomes a clickable 36px vertical bar with a glyph + serif-italic "terminal" / "canvas" label. Click the bar to restore — Duo remembers your previous split percentage so you don't snap back to 50/50. Distinct from the duo split presets above (which clamp to 20–80%); this is "hide entirely + restore on demand."

UIClick the left collapse-pill button to hide the terminal; the right one to hide the canvas. Click the resulting vertical rail to restore. The active button paints with an accent-orange fill while collapsed.

53

Reorder tabs in the working pane

Drag a tab horizontally onto another to swap positions, or right-click any tab → "Move tab left" / "Move tab right" for keyboard-friendly access. Pinned tabs stay leftmost (cross-zone drags silently rejected); the menu hides options at zone edges so you can't try to move a tab right when it's already rightmost.

UIDrag-and-drop within the working-pane tab strip, OR right-click → Move tab left / Move tab right.

54

Toggle line numbers in the markdown editor

Small # button in the bottom-left of the editor scroll-host. Click to render line numbers in the left gutter; click again to hide. Counts top-level blocks (paragraphs, headings, list items, blockquotes), one number per block — wrapped paragraphs count as one. Persists per-user across sessions; the same setting applies to every markdown tab.

UIClick the # toggle in the bottom-left of any markdown editor tab.

55

Smart duo open for local files

duo open ~/path/to/file.md now opens in the markdown editor (was: always the browser pane). HTML files with <meta name="duo-open-in" content="browser"> still open in the browser; HTML without that meta opens in the editor. Web URLs (http/https) unchanged. The CLI response includes a routedTo field ("editor" or "browser") so agents know where the file landed.

CLIduo open <path-or-url>

56

Open two files side-by-side in Split View

The canvas (right pane) can host a "main" file on the left and an "aux" file on the right. Useful for reading a spec next to its implementation, comparing two drafts, or keeping a smoke-walk page visible while you exercise the file it references. Drag the divider to resize (clamped 20–80%); double-click resets to 50/50. State persists across launch — relaunch Duo and the split is restored. Single-source-of-truth: a file can only be in one pane at a time. v0.6.5+

Swap when aux is occupied. Moving a new file into Split View while aux already holds a different file swaps them: the existing aux file moves back to main as a new file tab, and the new file takes the aux slot. The displaced file isn't lost — it lives on in main where you can keep working with it. (If the existing aux file has unsaved edits, you'll see a Cancel / Discard dialog before the swap — the editor unmounts during the pane move so unsaved edits would be lost. Save manually first if you want to keep them.)

UI — open / move into split: Right-click any file tab → Move to Split View; or right-click a file in the navigator / pinned list → Open in Split View; or with a file tab active, press ⌘\\. UI — close split + return to main: click the ✕ in the aux header (since v0.6.7, ✕ promotes aux content back to main as a fresh tab — the prior separate ⇤ button was redundant); or press ⌘⇧\\. CLIduo split-view open <path> · duo split-view state · duo split-view resize <pct> · duo split-view promote · duo split-view close. Per-page opt-in — pages in the browser pane can default their data-duo-path link clicks to Split View by adding <meta name="duo-path-target" content="split"> at the document head, or per-link via data-duo-target="split". Smoke-walk pages use this so step-link clicks land in the side without losing the walk doc.

56b

Pin a browser tab to Split View (worksheet next to its target)

A browser tab — worksheet, smoke walk, dashboard, any scripted page — can be moved to the Split View aux slot AND stay in a real Chromium tab. Scripts run, Copy buttons work, live duo:event emission still works. Pre-v0.6.7, moving a worksheet to split silently routed it through a script-blocked canvas iframe; that path is gone. v0.6.7+

UIRight-click a browser tab → Move to Split View. The tab leaves the main browser strip and pins to aux as a real WebContentsView. CLIduo split-view open-browser <id> (id from duo tabs). The aux ✕ promotes the tab back to the main strip.

57

Get a confirm before Split View swaps a dirty aux back to main

When the aux pane is showing a file with unsaved edits and you (or the agent) try to open a different file in aux, Duo fires a native macOS confirm dialog: Cancel (default — preserves the current state) or Discard changes (proceeds with the swap, losing the dirty file's unsaved edits during the pane move). v1 has no Save button — save the file manually first if you want to keep the work. Clean aux files swap silently with no dialog. The dialog fires on swaps; the explicit ✕ "discard split entirely" gesture skips the dialog (you opted in to the discard with the click). v0.6.5+

UITriggered automatically on any Split View move-into-aux attempt that would swap a dirty existing aux back to main: right-click menus, ⌘\\ chord, page-link [data-duo-path] clicks, CLI duo split-view open. All five entry points converge on the same dirty-swap gate.

37a

Diagnose why duo commands are failing

When a duo call fails inside Claude Code, the most common cause is the macOS Seatbelt sandbox blocking Unix-domain sockets — the bridge Duo uses by default. duo doctor probes both transports (Unix socket + TCP fallback), reports app/CLI version match, $DUO_SESSION presence, install-path discovery, and skill/agent-file presence. When the Unix socket is blocked but TCP works, it prints a clear "Claude Code sandbox detected (Unix socket blocked) — using TCP fallback" line so the failure mode is named instead of inferred. The sandbox-tolerant TCP fallback ships in v0.4.1; runs transparently without configuration.

CLIduo doctor

Workspace setup

Pin tabs you want always-available; install Duo's skill + agent + CLI in one click.

38

Pin a working-pane tab so it stays put

Right-click any tab in the right pane (browser, markdown editor, HTML canvas, image, PDF, preview) → Pin. Pinned tabs render with a pin glyph, sort to leftmost in the strip, and gate ⌘W behind a confirm modal so you don't dismiss them by reflex. Pin survives Duo restarts (stored at ~/.claude/duo/pins.json; matched by URL for browser tabs, by absolute path for file tabs).

UIRight-click a tab → Pin tab / Unpin tab. ⌘W on a pinned tab opens a confirm modal.

39

Install the skill + subagent + CLI in one click

On first launch (and after upgrades), a welcome banner appears at the top of Duo. Click Install — it copies the skill to ~/.claude/skills/duo/, the subagent to ~/.claude/agents/duo.md, the help files to ~/.claude/duo/help/, and the duo CLI binary to ~/.local/bin/duo. Bootstraps ~/.claude/duo/external-domains.json + ~/.claude/duo/priming.md if absent (never clobbered) and writes installed.json with the version. v0.3.0 also installs a load-bearing ~/.claude/duo/bin/claude shim and a SessionStart hook so claude sessions inside Duo arrive Duo-aware. If ~/.local/bin isn't on your shell $PATH, the success banner now shows an Add to PATH button — one click appends a fenced export PATH block to your ~/.zshrc (or ~/.bash_profile / ~/.config/fish/config.fish) so duo works from external Terminal/iTerm too. Idempotent — re-runs detect the fence and skip.

UIClick [Install] in the welcome banner. If the post-install row says "Use duo from outside the app?", click Add to PATH + open a new terminal.

40

Claude sessions inside Duo arrive Duo-aware

Every claude session you launch from a Duo terminal starts with knowledge of the workspace it's running in — the duo CLI verbs available, the file tree, the embedded browser, the canvas, the active selection. The agent can prefer duo view over cat, duo selection over scrolling for context, etc. without you typing a primer. Implementation: a PATH shim at ~/.claude/duo/bin/claude (installed at first launch) wraps the real binary with --append-system-prompt "$(cat ~/.claude/duo/priming.md)" when $DUO_SESSION is set; a SessionStart hook in ~/.claude/settings.json backs it up. Edit priming.md to customize.

UIOpen a new Claude tab (+ on the terminal strip or ⌘⇧T). Priming is automatic.
CustomizeEdit ~/.claude/duo/priming.md; survives Duo upgrades.

40b

Claude sessions OUTSIDE Duo also know about Duo

A small Duo-awareness block lands in your global ~/.claude/CLAUDE.md on first launch. Claude Code reads CLAUDE.md on every session start regardless of which terminal it's running in — Terminal.app, iTerm, VS Code's integrated terminal, agent worktrees not spawned by Duo. The block points at the duo skill, the duo subagent, the sandbox-troubleshooting reference, and the enterprise-deployments reference. Hook-independent — works in enterprise managed Claude Code installs where hooks are policy-disabled. Tagged with a <!-- duo:managed-vX.Y.Z --> marker; subsequent installs version-replace the block in place without touching your other content. Removable — once you delete the block, future installs respect that and never re-add. v0.6.6+

UIClick Install in the welcome banner. The block is added/refreshed automatically on each install + upgrade.
RemoveEdit ~/.claude/CLAUDE.md and delete the section between the <!-- duo:managed-v* --> and <!-- duo:end --> markers. Future installs respect the removal.

41

Canvas pages can drive the workspace (data-duo-action)

Add data-duo-action="claude:spawn", "terminal:send", or "browser:open" to any clickable element in an HTML canvas; clicking it dispatches the action through Duo's renderer. claude:spawn opens a new Claude tab (optionally with data-cwd + data-cmd); terminal:send writes data-text into the active PTY (with optional data-enter="true" to submit on the user's behalf); browser:open navigates a new browser tab to data-url. Trust gate v1: actions fire only on canvases under ~/.claude/duo/. Patterns: quiz with bidirectional Claude↔HTML loop, lesson runner with "next section" buttons, dashboard with starting-point links.

Try itOpen ~/.claude/duo/help/canvas-actions-demo.html from the file tree.
AuthorSee ~/.claude/skills/duo/examples/canvas-actions.md.

42

Submit a payload to the terminal on user's behalf with --enter

duo send --text "…" writes payload at the active terminal's PTY but doesn't press Enter — the user confirms. duo send --text "…" --enter appends a newline so the command runs immediately.
